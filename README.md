# FOCP-I C Programming Workspace

C programs written during Semester 1 of B.Tech CSE.

## Topics Covered
- Data types, input and output (`printf`, `scanf`)
- Conditional statements (`if-else`)
- Loops (`for`, `while`, `do-while`) and `break`
- Functions
- Basic calculators and real-life programs

## Programs

### Basics

| `scanf.c` | Taking user input with `scanf` |
