# FOCP-I C Programming Workspace

C programs written during Semester 1 of B.Tech CSE.

## Topics Covered
- Data types, input and output (`printf`, `scanf`, `fgets`)
- Conditional statements (`if-else`)
- Loops (`for`, `while`, `do-while`), `break` and nested loops (patterns)
- Functions and recursion
- Arrays (1D)
- Strings
- Pointers
- Basic calculators and real-life programs
